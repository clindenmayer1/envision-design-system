# Color

Color is expressed as **semantic roles**, never raw values. Components consume Tier-2 roles
(`--envision-t2-color-*`); the raw ramps live in Tier-1 and are never used directly. Roles map to
**purpose**: surfaces → `background`, text/icons → `content`, lines/dividers/rings → `border`.
Every swatch below is the live production token.

> **Selection & status are never colour-only** (WCAG 1.4.1): rings, checks, icons and text always
> accompany a colour. Cabinet/paint/material colours are **product data**, not tokens.
