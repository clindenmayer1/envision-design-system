# Spacing & Radius

## Spacing on a 4pt grid (`--envision-t1-spacing-*`)
Layout gaps and control padding come from the spacing scale. Components bind semantic spacing roles
(`--envision-t2-spacing-control-*`, `--envision-t2-spacing-container-*`) that resolve to these.
