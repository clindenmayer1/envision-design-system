# Typography

**Inter** is the UI typeface; Playfair Display is reserved for hero display. Components set type
**explicitly** from the scale (never `font: inherit`): e.g. Button and Tab are 14 / 600, Input 15,
form labels 14, PackageCard title 18 / 700. Body baseline is 16; 12px is never used for labels,
pricing or instructions.
