# Button

## Overview
`<envision-button>` triggers an **action** — submit, apply, select this design. It renders a real
`<button>` inside a shadow root, so keyboard activation, disabled focus behaviour and form
semantics come from the platform. It is styled entirely with production tokens and reconciled to
the shipped website (14px / 600, brand-CTA radius 10, outline = neutral hairline secondary).

Switch Type and Size below and the button updates in place, with the controls kept above the frame
so the change is always in view. The control strip is built from real `<envision-tab>` elements in
two tablists, so the documentation is composed from the system it documents.

<ButtonPlayground />

## Anatomy
`container` → `leadingIcon?` · `label` · `trailingIcon?`. The label is the button’s accessible
name (required). Icons are Material Symbols; the icon-adjacent gap is a spacing token. A spinner
replaces the intent while `loading`.

## When to use
- Committing an action: **Apply design**, **Save**, **Continue**, **Select this package**.
- The primary action on a surface (one **primary** per view); secondary actions use **outline**;
  lowest-emphasis inline actions use **ghost**.

## When not to use
- **Navigation between pages/views** → use **Link**.
- **Icon-only actions** (close, back, overflow, 3D controls) → use **IconButton**.
- Toggling a setting on/off → use **Switch**.

## Variants
<Canvas of={ButtonStories.Variants} />
`primary` = brand CTA (green fill). `outline` = neutral secondary (hairline border, dark text,
surface fill) — this matches the website’s secondary buttons, **not** a brand-green outline.
`ghost` = transparent, brand text, for lowest emphasis.

## Sizes
<Canvas of={ButtonStories.Sizes} />

Three sizes, backed by the Figma Button's **Size** variant and driven entirely by T3 tokens.

| size | padding block / inline | font-size | rendered height |
|---|---|---|---|
| `sm` | 12 / 12 | 12 | 40px |
| `md` (default) | 16 / 16 | 14 | 51px |
| `lg` | 20 / 24 | 16 | 61px |

Every value aliases an existing scale step, so the sizes sit on the 4pt grid. Heights are 2px
taller than the Figma masters (38 / 49 / 59) because the component carries a 1px transparent border
on all variants, so `primary` and `outline` align on a shared baseline.

`md` is the base and is applied to `.btn` directly, not through a `:host([size])` rule — a button
with no `size` attribute is a medium.

## States
- **default / hover / focus-visible / pressed** — from the platform + tokens; the focus ring is a
  2px brand ring (`--envision-t2-color-border-focus-default`).
- **disabled** — not focusable, blocks activation. <Story of={ButtonStories.Disabled} />
- **loading** — spinner replaces intent, `aria-busy=true`, re-activation blocked, but the control
  **stays focusable**. <Story of={ButtonStories.Loading} />

## Behaviour
`Enter` / `Space` activate. While `loading`, a capture-phase guard cancels activation so a double
submit can’t occur. `fullWidth` stretches the button to its container (RightRail apply, mobile CTAs).

## Accessibility
- Accessible name comes from `label`; icon-only buttons are the wrong tool (use IconButton).
- `disabled` reflects to the inner control and removes it from the tab order; `loading` sets
  `aria-busy` and keeps focus.
- Visible, unclipped 2px brand focus ring. WCAG 2.2 AA (see the Accessibility panel).

## Content considerations
Labels are short, action-first verbs (“Apply design”, not “Click here to apply”). Buttons don’t
wrap — long labels stay on one line; if a label is long, shorten the copy rather than the button.

## API
<Controls of={ButtonStories.Default} />

**Events:** `click` (blocked while `disabled` or `loading`).

## Token relationships
| Part | Token |
|---|---|
| Primary bg / content | `--envision-t3-button-primary-color-background/content-*` |
| Outline border | `--envision-t2-color-border-default-default` (hairline) |
| Outline / ghost text | `--envision-t2-color-content-primary` / `-brand` |
| Radius (CTA) | `--envision-t2-border-radius-container-md` (10) |
| Padding | `--envision-t3-button-{small,medium,large}-padding-block/-inline-default` |
| Type | `--envision-t3-button-{small,medium,large}-font-size-default` / `--envision-t1-font-weight-600` |
| Focus ring | `--envision-t2-color-border-focus-default` |

## Implementation
```html
<envision-button variant="primary" label="Apply design"></envision-button>
<envision-button variant="outline" label="Cancel"></envision-button>
```
```tsx
import { Button } from '@envision/react';
<Button variant="primary" label="Apply design" onClick={apply} />
```
